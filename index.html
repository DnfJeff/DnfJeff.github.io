Daggerfall · map & tools

Daggerfall Interactive Map

out now

The whole Iliac Bay on the game's own map art. Zoom from the overview down to a town's streets, find any shop, guild or temple by name, follow the roads, and keep notes and a journal for a playthrough. Nothing is uploaded and there is nothing to install — it runs in the browser, and saves to a file you keep. There is also a portable Windows build: one .exe with the map data inside it, which can read your own install and saves so the map follows your character.

Daggerfall · mod

Daggerfall VoiceBox

early · v0.4.0

Spoken dialogue for Daggerfall Unity. NPC greetings, answers, quest cards and notices are read out as they appear on screen, by a text-to-speech engine running on your own PC — no internet, no recorded voice packs, and it works with any quest or mod that puts text on screen. The mod picks a voice for whoever is speaking; the engine streams the speech back sentence by sentence, so the first line lands in a fraction of a second.
